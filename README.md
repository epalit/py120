# Python Programming (PY120) – 2026

This repository contains exercises and notes from working through Launch School’s **Object-Oriented Programming** course.

Building on the foundations established in PY110, this course focuses on understanding object-oriented programming in Python, including how to design, structure and work with classes and objects effectively.

The goal at this stage is to develop a solid understanding of OOP principles, write well structured object-oriented code, and become more confident reading, debugging and designing larger programs.

## Focus Areas

- Classes, objects, instance variables and methods
- Class variables, class methods and static methods
- Inheritance, mix-ins and polymorphism
- Encapsulation and working with collaborator objects
- Object equivalence, truthiness and operator customisation
- Object-oriented design principles and CRC cards
- Reading, debugging and designing object-oriented code

## Structure

- Separate directory for each lesson
- Lesson notes in `.md` files inside the `notes` directory for each lesson
- Exercise solutions in `exercises` directory

## Running Code
